The Club of Steven Publisher

A desktop tool for managing the authorized channel’s content with the YouTube Data API.

Purpose

The Club of Steven Publisher is an owner-operated Windows desktop application. It prepares episode manifests, publication metadata and editable calendars, and maintains local records to help prevent duplicate uploads.

It connects only to the authorized The Club of Steven channel. Uploading or scheduling new videos requires the owner’s explicit approval for the specific file and operations. Existing publications are reconciled without changing them.

Google access

The application requests YouTube account access to identify the authorized channel and manage its videos, captions, thumbnails and playlists when approved. The requested permission is youtube.force-ssl, which Google describes as access to see, edit and permanently delete YouTube videos, ratings, comments and captions. The current application does not implement deletion of YouTube publications.

OAuth consent takes place in the system browser. Tokens are encrypted locally using Windows DPAPI. Publication metadata and logs are stored locally and are not encrypted by the application. This website does not receive OAuth tokens, videos or channel records.

Availability and status

This application is for the channel owner’s use, not a public publishing service. Technical preparation is distinct from a real upload: an API upload still requires a reviewed new asset and specific authorization. This website does not assert that Google has verified or approved the application.
