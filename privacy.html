Privacy Policy

The Club of Steven Publisher

Effective date: October 27, 2026

Who operates this application

The Club of Steven Publisher is an owner-operated desktop tool for the authorized The Club of Steven channel, a Grupo Armas project. Contact: theclubofsteven@gmail.com.

Data accessed and purpose

After the owner grants Google OAuth consent, the application uses YouTube Data API access to identify the channel and read its accessible uploads, titles, descriptions, language metadata, privacy and scheduling status, durations, original file information, captions and playlist information as needed. These records support publication planning, reconciliation, duplicate prevention and troubleshooting.

For a specifically authorized new upload, the application can send the selected video, metadata, thumbnail, captions, translations, audience and synthetic-content declarations, privacy/scheduling choices and playlist instructions to Google. No publication authorization is inferred from a file’s existence.

Permissions and control

The OAuth permission youtube.force-ssl grants broad YouTube account capabilities. The application verifies the authorized channel and checks an operation-specific owner approval before publishing. Its current code does not provide a function to delete existing YouTube publications.

This page is informational and does not collect Google sign-ins, OAuth credentials, channel records or media. The desktop application handles OAuth through the system browser and a loopback callback on the same computer.

Storage and security

OAuth tokens and resumable upload session references are stored outside the project and encrypted with Windows DPAPI for the Windows user. Local publication manifests, API snapshots, identifiers, URLs, schedules, file hashes and error/status records are stored on the owner’s computer and are not encrypted by the application. The owner is responsible for access to that computer and any backups.

Credentials are excluded from the public website. The application does not sell Google user data, use it for advertising, or send it to AI model training services. Its use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Retention, removal and revocation

Local tokens and publication records remain on the owner’s computer until the owner removes them. The current application does not automatically purge local records when Google access is revoked. Revoking access and removing local data are separate actions; the owner should remove API-derived records and local tokens when they are no longer needed or consent is withdrawn. Removing local records does not delete videos from YouTube and can remove duplicate-prevention history.

To revoke Google access, open Google Account third-party connections and remove this application’s access. The application will then need new consent to reconnect. For help removing local data, contact the operator at the address above. Data retained by Google remains subject to Google’s own policies and account controls.

Service providers and visitors

The application exchanges authorized account data with Google for YouTube operations. These informational pages are hosted by GitHub Pages. GitHub may process technical connection information under the GitHub Privacy Statement. These pages do not add analytics, advertising, forms or tracking scripts.

See also the Google Privacy Policy and YouTube Terms of Service.

Changes

This policy may be updated when the application’s actual data practices change. The effective date above identifies the current version. No claim of Google verification or approval is made.
